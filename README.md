# Warranty Center · 质保中心

数码电商售后必备：序列号质保登记、到期查询、在线报修一体。

## 功能

- **SN 解析引擎**：`前缀-年份-流水号` 格式校验，前缀映射产品线（键盘/耳机/音箱/手表）
- **质保登记**：购买日期 + 渠道，防重复登记
- **质保查询**：状态三档（在保 / 即将到期 ≤30 天 / 已过保），进度条展示已消耗比例
- **质保政策随产品线**：键盘 24 个月、耳机音箱 18 个月、手表 12 个月，覆盖范围自动带出
- **在线报修**：在保设备一键发起，故障类型 + 描述 + 联系方式，生成工单号
- localStorage 持久化

## 演示 SN

`KB2026-88341`、`HP2026-10293`、`SP2025-55612`、`WM2026-00314`（年份可换）

## 运行

浏览器直接打开 `index.html`。
